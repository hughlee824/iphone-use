# 隐私与数据流

设备控制在 Mac 和连接的 iPhone 上执行。AI 客户端读取截图、界面文字和任务上下文，并根据配置将这些内容发送给所选模型。使用云端模型时，手机内容可能离开本机。

[English](privacy.md)

## 各部分负责什么？

| 组件 | 职责 | 需要关注的数据 |
| --- | --- | --- |
| iPhone | 运行目标 App，提供设备观察并接收操作。 | 可见应用内容；Runner 模式还可能读取可用辅助功能元素。 |
| Mac 上的 iPhone-use | 维持设备会话，返回观察与动作结果。 | 截图文件、观察文本、会话状态与诊断输出。 |
| AI 客户端 | 执行命令、读取图片、组织模型请求并展示结果。 | 图片、工具输出、任务历史，以及客户端日志与同步。 |
| 所选模型服务 | 根据收到的数据规划动作、理解结果。 | 实际请求中包含的图像与文字；保留方式取决于服务与账号设置。 |

两种控制模式都可能向客户端提供手机内容。使用哪个模型，以及发送哪些数据，取决于客户端配置。

## Mac 上可能保留什么？

会话产物默认位于 `/private/tmp/iphone-use-<uid>`，也可由 `IPHONE_USE_STATE_DIR` 指定。偏好位于 `~/.iphone-use/config.json`，发布包的 Runner 准备状态位于 `~/Library/Application Support/iphone-use`，预览访问凭据位于 `~/.iphone-use/previews/<port>/`，受 `IPHONE_USE_CONFIG_DIR` 控制；签名私钥保留在 Keychain。详见[架构](architecture.md)和[模式配置](control-modes.md)。

截图、录屏、设备标识和日志都应按潜在私密数据处理。断开会话不等于删除保存的录屏、复制文件、客户端历史或模型服务端记录。本地预览只用于观看；关闭浏览器标签不会停止预览服务或断开手机。断开后画面停止，但预览 URL 不会失效；同一设备以后明确启用预览时，旧链接仍可访问。需要使旧链接失效时，按[预览访问撤销](local-preview.md#稳定入口与原标签页重连)操作。

## 使用个人 App 前

- 核对客户端使用的模型端点、读图工具，以及数据保留、日志和同步设置。
- 先用“设置 → 通用”等简单导航任务测试，并检查截图是否出现设备信息或私人通知；公开演示前检查完整画面。
- 若要求截图和界面文字不离开本机，需要核验本地推理，以及处理这些数据的客户端、日志与自动回退路径。仅使用本地 CLI 不能证明这一点。
- 报告问题时只分享经过检查和脱敏的证据，不公开私人截图、设备标识、签名描述文件或凭据。漏洞使用[私密报告渠道](../SECURITY.md)。

模型服务的数据保留规则请查阅所选服务的政策及账号设置。
